# 微信应用申请、配置与验收

状态：2026-11-03用户确认尚无平台应用与回调域名。今天提供网站应用扫码登录实现，手机/桌面均可访问响应式页面；这不等于已实现原生App或小程序登录，手机单机微信内授权也不是本版本范围。

## 申请顺序

1. 用浏览器打开微信开放平台 https://open.weixin.qq.com/ ，本人注册/登录，查看账号中心可用的开发者资质及管理中心“网站应用”。主体资格、认证、资料与费用以当前后台为准，不承诺个人账号一定可申请。若个人主体不具备权限，先核对学校/团队是否有获授权使用的应用；不要借用来源不明的AppSecret。
2. 准备可用网站和域名，在“网站应用”创建check@collect，按当前后台要求填写介绍、图标、网站资料及授权回调域，申请微信登录并等待审核。本人完成实名、资质与条款步骤。
3. 获批后取得AppID与AppSecret。AppSecret只放部署主机环境变量，不放聊天、前端、Git或截图。
4. 部署本站HTTPS地址，将回调域配置成该站点域名。程序完整回调路径固定为`https://你的域名/auth/wechat/callback`，域名必须与微信平台审核配置一致。
5. 配置后重启服务：先真实扫码登录，再注册另一个本系统账号并绑定未被占用的微信身份，退出后用微信登录应回到绑定账号。保存不含code、state、openid、密钥的验证记录。

## 有平台配置后

在本机终端设置`PUBLIC_ORIGIN`、`WECHAT_APP_ID`、`WECHAT_APP_SECRET`、可选`CHECK_COLLECT_DB`，变量示例见`.env.example`；程序直接读环境变量，不自动加载.env文件。HTTPS代理指向本机8765端口，代理应限制请求速率、连接数及请求大小，且不要记录授权回调查询参数；不要直接把开发HTTP端口公开。生产备份与权限需另行核对。

绑定的是微信官方授权身份（appid+openid），不是让用户填写可搜索的微信号或微信密码。首次微信登录自动建立账号；已有本地账号先登录，再点“绑定或核验微信”。一个微信身份不能覆盖绑定到另一个账号，同一账号本版本不能直接替换已有微信绑定。所有新账号均没有预授予采集/核验/第三方权限，业务角色将在后续日程实现。

## 证据边界

本地测试覆盖账号哈希、绑定唯一性、授权状态与浏览器会话、过期/重放、退出及HTTP流程；微信响应是测试注入值。只有配置真实应用、在真实授权回调完成扫码和绑定后，R13/R14才可标记最终验收通过。当前不保存昵称、手机号、微信访问令牌；会话有效期2小时。

官方依据： https://developers.weixin.qq.com/doc/oplatform/Website_App/WeChat_Login/Wechat_Login.html 。11/3用HTTP读取并解压官方响应核对：网站应用须审核并取得微信登录权限，使用snsapi_login；授权码由服务端交换，推荐state校验。网站应用流程与小程序wx.login、公众号网页授权、原生App SDK分别不同。
