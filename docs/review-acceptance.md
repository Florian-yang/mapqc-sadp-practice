# 11月5日核验与重采

## 使用

先注册采集者与核验者账号。在核验账号首页查看用户ID，由可信本机维护者执行下面的命令，数据库路径使用原CHECK_COLLECT_DB配置。网页不能自行获得核验权限。

```powershell
& 'C:/Users/flori/AppData/Local/Programs/Python/Python313/python.exe' -m check_collect.roles 核验者用户ID
```

核验者进入工作台，查看他人POI照片并填写错误说明。原采集者在“我的采集”看到问题，可修改名称、类别和描述，或进入相机重新拍照定位；也可写明理由驳回。更新和重采生成新版本并返回待核验，旧照片与描述保留。驳回只记为有异议，讨论和第三方处理留到11/7。

## 验证与边界

39项Python测试通过，其中12项新增核验测试；另有6个前端合成场景。实际本地HTTP走通标错、更新、重采、驳回及版本查看，验证普通用户、其他采集者和本人核验被拒绝。测试还覆盖旧v0.5数据库迁移、并发重复标错、事务失败回滚、新照片失败清理及已有文件保护。

每次标错同时写入event_outbox，目标为原采集者；处理结果事件指向核验者。当前没有消费者，不标记已发送或已收到，不计作中间件接入。自动测试使用合成照片、坐标和设备API；HTTPS手机重采、真实微信和公网部署仍待验收。未提前实现聊天、第三方裁决、地图或OCR。
