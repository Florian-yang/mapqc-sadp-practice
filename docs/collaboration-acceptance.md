# 讨论与异议处理

## 讨论

登录后进入“工作讨论”，采集者和核验者分别使用各自的角色群。在POI处理记录中选择“私聊讨论这项错误”，与该问题的原核验者或采集者交流。同一错误共用一个私聊。

聊天读写检查当前角色与参与关系，重复发送请求按请求标识去重。消息保存后生成NATS通知。

## 第三方裁决

采集者驳回错误后，双方任一方填写异议说明。系统从第三方工作人员中选择一位，并排除原采集者和核验者。维护者可通过以下命令授予已有账号第三方角色：

```powershell
python -m check_collect.roles 用户ID third_party
```

被指派者进入任务，重新拍照、自动定位，填写说明和结论。结论包括原错误成立或不成立，两种情况均保存第三方采集版本，记录采集账号，通知双方并结束本轮处理。

原始照片、采集者复核和裁决记录可回看。第三方可查看所分配的任务和POI照片；双方私聊只向讨论参与者开放。
