# 11月7日讨论与异议处理

## 使用

登录后进入“工作讨论”。采集者和核验者分别进入各自角色群；在POI处理记录中点击“私聊讨论这项错误”，可与原核验者或采集者沟通。同一错误共用一个私聊，其他用户不能加入。消息保存后生成NATS通知，发送标识用于重复请求去重。

采集者驳回错误后，双方任一方可填写异议说明，系统从已配置的第三方工作人员中选择一位，排除原采集者和原核验者。没有独立人选时提示维护者配置，不会由当事人自行裁决。原有核验角色命令兼容，第三方角色由可信本机维护者授予：

```powershell
& 'C:/Users/flori/AppData/Local/Programs/Python/Python313/python.exe' -m check_collect.roles 用户ID third_party
```

被指派者从通知或“异议处理”进入任务，重新拍照、自动定位，填写名称、类别、描述、核验说明和结论。结论可为原错误成立或不成立；两种结果都保留第三方重采版本，并作为最终数据。原始照片、采集者复核和裁决过程可回看，新快照记录实际采集账号。裁决后冻结本轮修改，并向双方各发送一次结果通知。

## 记录与权限

聊天消息或裁决，各自与对应通知事件在同一SQLite事务保存。NATS沿用11/6的真实发布、消费确认和收件箱去重。群通知只保存消息标识，不携带聊天正文；权限变化后，读写聊天重新检查角色。第三方只可访问分派给自己的任务与POI照片，不能查看双方私聊。
