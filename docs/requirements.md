# 需求与验收清单

选题为人工地图数据质量检查工具，运行于单台Windows PC，离线使用。操作人是质检员：打开文件，查看图形或文本，在指定位置登记错误，保存后查询。下面的业务功能均为计划要求，v0.1仅完成启动与打包骨架。

| 编号 | 功能 | 验收方法 | 计划日期 |
| --- | --- | --- | --- |
| F1 | 加载GeoJSON与普通文本 | 小样例中的要素和文本可读出；坏文件有提示 | 11/2 |
| F2 | 显示数据并选择位置 | 图形点击转换为数据坐标；文本记录行号 | 11/3 |
| F3 | 登记位置、类型、描述，自动编号 | 连续登记不重号，空内容被拦截，错误位置可见 | 11/4 |
| F4 | 保存、重开JSON错误记录 | 重开后各字段一致，再新增也不重号；失败时保护旧文件 | 11/5 |
| F5 | 按关键字查询并定位 | 在当前地图的编号、类型、描述中匹配；空结果清楚，换图不串记录 | 11/6 |
| E1 | 通过统一接口增加PNG栅格 | 记录像素行列，验证登记与查询逻辑的复用范围 | 11/7 |

E1是用于检验可修改性的扩展。基本图形需求由GeoJSON覆盖。若进度超时，先保住F1—F5与课程必交材料。

## 环境限制

默认输入为本机文件，不依赖服务器。界面使用PySide6，软件通过PyInstaller打包。当前实测环境见验证记录；只验证过的平台不扩大写成跨平台测试已通过。其他平台的依赖与重新打包边界在报告中说明。

| 关注点 | 要留下的证据 |
