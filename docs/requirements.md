# 功能说明

采集者用手机拍照，应用自动获取位置，连同类别、名称和描述提交。核验者标识错误并填写说明，原采集者可更新、重新采集或驳回。照片和处理过程按版本保存。

| 功能 | 实现 |
|---|---|
| 账号与权限 | 本地账号、微信登录与绑定；采集者、核验者、第三方角色 |
| 采集与核验 | 照片及位置上传、标错、更新、重采、驳回、历史版本 |
| 讨论与裁决 | 问题私聊、采集者群、核验者群、第三方重采终裁 |
| 消息 | NATS群发与点发、本人收件箱、已读标记 |
| 地图 | 按类别和进展显示POI、错误标识、路线及位置跟随 |
| 文字识别 | 百度OCR识别照片文字，给出分类建议 |

手机已通过电脑热点HTTPS完成照片与自动位置上传，核验通知经NATS送达。11月13日完成微信测试号绑定、直接登录原账号和手机百度OCR识别。电脑端可查看已有POI地图、照片及处理进展，铃铛显示本人未读通知。当前为本机与热点部署；公网访问、现场到达导航和第三方现场重采未作实地演示。
