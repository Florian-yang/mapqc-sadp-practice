# 地图、导航与文字识别

登录后进入“POI地图”，按类别、处理进展查询。点开标记可查看照片、当前版本和错误状态。地图只显示本人可读的条目；被指派的第三方只能访问分派给自己的争议。

## 地图与路线

本地Leaflet 1.9.4显示OpenStreetMap底图，保留署名，按可见区域加载瓦片。坐标统一使用WGS84。点击“导航至此POI”后，设备取得起点，服务器向OSRM请求驾车路线，页面显示道路折线、距离和分步指引，并跟随当前位置；停止按钮结束位置跟随。当前不提供语音播报和偏航重算。

仲裁中显示橙色，待处理错误显示红色，已裁决显示绿色，待核验显示蓝色。路线服务失败时显示错误；权限或目标版本变化时拒绝旧结果。

## 文字识别

当前默认接入百度通用文字识别（标准版）。在POI地图中打开照片，勾选同意将该照片发送至百度OCR后识别。页面显示文字与分类建议，类别由采集者确认修改。

在百度智能云文字识别控制台创建应用，开通通用文字识别（标准版），确认免费额度或计费设置。将应用凭据配置到运行服务的终端环境：

```powershell
$env:BAIDU_OCR_API_KEY='本机填写API Key'
$env:BAIDU_OCR_SECRET_KEY='本机填写Secret Key'
```

从这个终端启动服务。`.env.example`是样例，程序不自动读取它。密钥只供后端使用，不随源码提交。

后端先获取并缓存访问令牌，再提交选定版本的JPEG照片；令牌失效时刷新一次。当前应用限制照片为1MB以内。结果按照片版本、摘要和语言缓存，切换到百度后不会把旧OCR.Space缓存当作百度结果。网络、授权或额度异常会返回提示，不改动POI内容。

接口依据：[通用文字识别](https://ai.baidu.com/ai-doc/OCR/zk3h7xz52)、[鉴权说明](https://ai.baidu.com/ai-doc/OCR/Ck3h7y2ia)。

## 11月8日验证

通过本应用HTTP入口调用真实OSRM，返回1189.4米、191.3秒、76个路线点和8步指引。真实OCR.Space识别合成招牌，返回“MAPQC SHOP 42”和“兴旺商店”，建议商铺；原POI类别保持other、版本保持1。当天另有一次纯英文探针，共两次OCR测试调用。

浏览器已核对账号登录、真实底图、点位与照片弹窗。修复非地图页no-referrer使同源表单Origin失效的问题，改用same-origin；地图按瓦片政策使用strict-origin-when-cross-origin。自动检查在OCR确认框处中断，浏览器中的识别结果展示另列复测。完整日志见[evidence/2026-11-08](../evidence/2026-11-08)。

坐标、照片和账号均为合成数据。个人OCR Key尚未配置；HTTPS手机相机/GPS与到达导航、第三方现场采集、微信和公网演示列入后续验收。

依据：[OSRM接口](https://project-osrm.org/docs/v5.24.0/api/)、[OSM瓦片政策](https://operations.osmfoundation.org/policies/tiles/)、[OCR.Space接口](https://ocr.space/ocrapi)和[测试Key说明](https://ocr.space/faq)。
