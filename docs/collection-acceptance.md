# 11月4日移动采集验证

## 当前使用

安装requirements-web.txt（新增Pillow），启动`python -m check_collect.server`。登录后点击“加入采集者”，进入“采集POI”。打开相机、拍照并自动定位，填写名称、类别、描述后上传；“我的采集”显示本人的照片、位置、精度与待核验状态。位置没有手工输入框。此入口只授予普通采集角色。

拍照从当前视频帧取得JPEG，随后请求一次新位置（maximumAge=0），定位成功才开放上传。拍摄时间与定位时间差不得超过20秒，上传时二者均在最近10分钟内（允许客户端时钟提前30秒）。照片最大4MiB，服务端接受JPEG/PNG，解码尺寸不超过1200万像素并重编码为JPEG。未实现客户端离线队列，超过时间需重拍。

## 已验证及边界

- 本地实际HTTP：账号注册/登录、加入采集者、上传、重启后读取、照片读取、未登录/其他用户拒绝、来源校验。
- 图片与元数据：有效照片往返；缺失/非有限坐标、异常精度、旧时间、间隔过大、坏图、非法类别被拒绝；重复上传不重复建档，同一拍摄标识不能替换位置内容。
- 前端处理器：Node VM内使用合成DOM、相机与定位API，检查成功上传、拒绝定位与失败重拍，以及异步事件对象失效时仍能清空表单。没有调用物理相机或GPS。
- 尚未验证：真实手机摄像头、定位精度、权限拒绝后的浏览器体验、HTTPS公网访问、跨设备演示。设备数据由客户端报告，不能据此保证防定位伪造或照片内容与位置一致。
