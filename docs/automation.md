# 每日执行配置

2026年10月31日已在当前聊天创建Codex每日自动任务，名称为“MapQC综合实践每日推进至11月9日”，编号`mapqc-11-9`，状态为启用。

- 时间：每天北京时间21:30触发。常规计划到11月9日，11月10—11日保留自动补漏，最晚11月11日22:00结束。
- 顺序：读取项目入口及当天计划，开发或设计，验证，更新图文、日记与周材料，完成后提交并推送。
- 每次先检查截至当天的欠项。哪天中断，下次从最早未完成环节继续，先补齐遗漏或失败项，再做当天任务；最多追到当天，不提前实现未来任务。
- 核对中断前的改动、测试证据与远端状态，避免覆盖工作或重复提交。补做注明原计划与实际执行日期，工时和结果按实际记录。
- 验证通过后提交对应代码与版本；验证失败则继续修复，问题如实保留。当天及既往任务都已完成时只核对新问题，不做空提交。
- 11月2日、11月9日分别汇总第8、9周材料；如中断，在恢复后补齐日记、周材料和Excel工作副本。
- 11月10—11日仅补原计划欠项、验证与交付，不扩展范围。完整周期已验收并推送时不再开发，截止后保留未完成项的实际状态。
- 日常成功执行不额外通知；遇到需要本人处理的登录、授权或关键信息问题时再提出具体需要。
- 本地任务需要电脑开机且Codex应用保持运行。配置成功不代表未来某次执行已经完成，进展仍以日记、验证记录和GitHub提交为准。
